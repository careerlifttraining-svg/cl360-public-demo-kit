How to Use This Tool

Read Question

Plays the current question aloud when your browser supports text-to-speech.

Start / Continue Dictation

Adds spoken words to the current answer. You stay on the same question until you choose to move.

Save & Next

Saves your current work in this browser and moves you forward.

Review My Answer

Shows prompts that may help you add useful detail without changing your meaning.

Final Review

Shows every answer together and flags blanks before export.

Backup

Lets you save a local copy and restore it later.

Accessibility Statement

CL360 Accessible Forms Assistant is designed to reduce barriers for people who may have difficulty handwriting, typing, reading small text, navigating long forms, or maintaining hand use for extended periods.

Current accessibility features include large controls, keyboard focus indicators, optional larger text, contrast controls, read-aloud support, speech-to-text support where available, local save/resume, and mobile-responsive layout.

This is an evolving accessibility product. Browser and device support can vary, especially for speech recognition.

Privacy & Session Controls

Privacy: This prototype stores answers only in this browser using local storage. It does not upload answers to a CL360 server. On a shared device, export your backup if needed, then clear the session when finished.

Use “Start New Session” when beginning a different person's form. Use “Clear All Saved Data” before leaving a shared device.

Final Review Before Export

Review every answer in one place. Blank questions are flagged so you can jump back and complete them before exporting.

If speech-to-text is unavailable

You can still tap an answer box and use the microphone on your Android keyboard. That uses your phone's built-in dictation instead of the web speech API.
